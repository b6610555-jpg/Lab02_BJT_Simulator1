# Design Doc: BJT Common-Emitter DC Bias Web App (ENG29 2121)

## Intent and Why

นักศึกษารายวิชา ENG29 2121 ต้องการเว็บแอป Flask หน้าเดียว ที่คำนวณจุดทำงานกระแสตรง (DC operating point) ของขยายสัญญาณแบบ Common-Emitter จากค่าองค์ประกอบที่ป้อนเข้ามา แสดงผลพร้อมหน่วย ตรวจสอบความถูกต้องของค่าอินพุต และเตือนเมื่อทรานซิสเตอร์อยู่ในโซนตัด (cutoff) หรืออิ่มตัว (saturation) นอกจากนี้ต้องเปรียบเทียบผลลัพธ์กับการคำนวณอิสระอีกหนึ่งทางบนหน้าเว็บเดียวกัน เพื่อให้อาจารย์ตรวจสอบความสอดคล้องได้ทันที

ขอบเขตจำกัดเฉพาะ DC bias เท่านั้น ไม่มีกระแสสลับ (AC) เชิงชั่วขณะ (transient) ตัวแก้วงจรเต็มรูปแบบ หรือ FET

## Goals / Non-Goals / Anti-Goals

### Goals
- แอป Flask รันบน localhost ได้จริง
- แยกตรรกะวิศวกรรม (bias.py, reference.py) ออกจากเส้นทาง Flask (app.py) และเทมเพลต (templates/)
- รับอินพุต: VCC, R1, R2, RC, RE, β, VBE
- แสดงจุดทำงานพร้อมหน่วย (V, mA, µA, Ω)
- ตรวจสอบค่าอินพุตที่ผิดพลาดและแจ้งกลับไปยังฟอร์ม
- เตือนโซน cutoff / saturation (ไม่ขัดข้องการทำงาน)
- แสดงผลจากสองวิธีคำนวณข้างกัน พร้อมความต่าง絶对และร้อยละ
- มีทดสอบอัตโนมัติครอบคลุมด้วย pytest
- คอมมิตขึ้น GitHub และสาธิตบนlocalhost ภายในวันนี้

### Non-Goals
- การวิเคราะห์กระแสสลับ (AC)
- การจำลองเชิงชั่วขณะ (transient)
- ตัวแก้วงจรเต็มรูปแบบ / มัลติมิเตอร์เสมือน
- MOSFET / FET
- ฐานข้อมูล / ระบบล็อกอินผู้ใช้
- เฟรมเวิร์ก JavaScript หน้าเว็บ

### Anti-Goals (ทำแล้วถือว่าล้มเหลวแม้โค้ดจะใช้งานได้)
- ตรรกะวิศวกรรมปนกับโค้ด Flask จนทดสอบ standalone ไม่ได้
- แสดงผลเพียงวิธีเดียว (ขัดต่อข้อกำหนด "เปรียบเทียบกับการคำนวณอิสระ")
- ไม่มีทดสอบอัตโนมัติ

## Constraints

- Flask + pytest เท่านั้น (ไม่ติดตั้ง dependency อื่นเพิ่ม)
- `bias.py` และ `reference.py` ต้องไม่นำเข้าอะไรจาก Flask
- หน่วยใช้ระบบ SI (V, Ω, ไร้มิติ)
- ค่าเริ่มต้นของฟอร์มต้องใส่ไว้ล่วงหน้า เปิดแอปแล้วคำนวณได้เลย
- ต้องคอมมิตและสาธิตบน localhost วันนี้ (10 พ.ย. 2026)
- ไม่มี `gh` CLI ในเครื่อง ต้องสร้าง GitHub repository แล้วบอก remote URL หรือผู้ใช้ดันขึ้นเอง

## Approaches Considered

### A. สองวิธีคำนวณบนหน้าเดียว (เลือกแล้ว)
- `bias.py`: ลดวงจรเป็น Thévenin ที่ขั้วเบส แล้วคำนวณ IB, IC ตามสูตรตำรา
- `reference.py`: เขียน KCL ที่โหนดเบสและลูปอิ미터 เป็นสมการเชิงเส้น 2×2 แก้ด้วยกฎคราเมอร์
- หน้าเว็บแสดงทั้งสองคอลัมน์ข้างกัน พร้อมความต่างของ IC และ VCE
- ข้อดี: อิสระจริง คนละพีชคณิต ฟิสิกส์เดียวกัน เห็นตาได้ชัดว่าตรงกัน
- ข้อเสีย: เพิ่มโค้ดประมาณ 30 บรรทัด

### B. หนึ่งโมดูล มีสองฟังก์ชันใช้ตัวกลางร่วมกัน
- ข้อดี: เขียนเร็ว กระทัดรัด
- ข้อเสีย: "การคำนวณอิสระ" ไม่จริง เพราะใช้ตัวเลขกลางชุดเดียวกัน ไม่ผ่านข้อกำหนดแล็บ

### C. ตัวแก้เชิงตัวเลขสำหรับเส้นทางอิสระ
- ข้อดี: อิสระอย่างแท้จริง
- ข้อเสีย: ต้องเพิ่ม numpy/sympy ตัวแก้สมการเชิงเส้น เกินขอบเขต "เล็กที่สุดที่ใช้งานได้"

## How It Works (As Decided)

1. ผู้ใช้เปิดหน้า `/` เห็นฟอร์มใส่ค่า 7 ตัว (มีค่าเริ่มต้นใส่ไว้แล้ว)
2. กด Calculate → Flask route `POST /` รับค่า ตรวจสอบ แล้วเรียก `bias.py` และ `reference.py`
3. ถ้าค่าผิดพลาด → รีเทิร์นเทมเพลตเดิมพร้อมข้อผิดพลาดและค่าที่กรอกไว้เดิม
4. ถ้าถูกต้อง → คำนวณทั้งสองทาง แสดงตารางผลลัพธ์ข้างกัน (Thévenin | อิสระ | ความต่าง) และคำเตือนโซนถ้ามี

### สูตรหลัก (bias.py — Thévenin)
- VBB = VCC × R2 / (R1 + R2)
- RB = R1 ‖ R2
- IB = (VBB − VBE) / (RB + β × RE)
- IC = β × IB
- IE = (β + 1) × IB
- VE = IE × RE
- VC = VCC − IC × RC
- VCE = VC − VE

### สูตรอิสระ (reference.py — KCL 2×2)
สมการเชิงเส้นในตัวแปร (VB, IB):
- (1/R1 + 1/R2 + 1/(β×RE))·VB − (1/(β×RE))·VE-ish → แก้ด้วยกฎคราเมอร์
- (รายละเอียดอยู่ใน reference.py ตอนเขียนจริง)

### โซนการทำงาน
- VBB ≤ VBE → Cutoff (IB ≤ 0 โมเดลใช้ไม่ได้)
- VCE < 0.2 V → Saturation (เตือนว่า IC จริงต่ำกว่าเพราะจำกัดด้วย β)
- อื่น ๆ → Active (ปกติ)
